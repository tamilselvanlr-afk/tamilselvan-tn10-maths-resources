# TN 10th Maths Resources – Version 3

A responsive bilingual (Tamil/English) Class 10 Mathematics learning portal for the Tamil Nadu Samacheer Kalvi syllabus.

## Files
- `index.html` – page structure
- `styles.css` – responsive design, dark mode and print layout
- `content.js` – bilingual chapter content, concepts, worked examples and practice questions
- `app.js` – language switch, chapter navigation, answer reveal, mock test and local progress

## Deploy on GitHub Pages
1. Extract this ZIP.
2. Open your repository: `tamilselvan-tn10-maths-resources`.
3. Choose **Add file → Upload files**.
4. Upload/replace the four website files at repository root: `index.html`, `styles.css`, `content.js`, `app.js`.
5. Commit changes to `main`.
6. Settings → Pages → Deploy from a branch → `main` → `/(root)`.
7. Wait for the deployment, then refresh your existing Pages URL.

## Important content note
This version follows the eight-chapter structure and key topic headings in the supplied Tamil and English Tamil Nadu Standard 10 Mathematics textbooks. The explanations and sample problems here are original study aids, not a reproduction of the textbook. It is an expanded learning foundation, not yet a complete worked-answer key for every numbered textbook exercise. Please check each exercise against the student's current prescribed edition. The mock test currently uses short-answer self-check questions; it does not yet auto-grade free-text answers.
